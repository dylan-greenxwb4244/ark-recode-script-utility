## What the Toolkit Does

Ark Re:Code Tools provides a browser workspace for planning Ark Re:Code characters, evaluating equipment, and managing competitive battle information. Its character database includes bilingual names, build guidance, speed calculations, and equipment planning tools to help players prepare teams and compare setups.

In addition to build planning, the toolkit can record PvP and GvG activity, review previous battles, provide strategy suggestions, and reference community-maintained counters. Information may be kept in browser local storage, accessed offline where supported, or synchronized through Google Sheets for an additional data-management option.

## Included Tools

- Maintain guild battle teams and their recorded results.
- Examine PvP battle history alongside relevant strategy recommendations.
- View character names in two languages and review suggested builds.
- Evaluate equipment with weighted attributes and target speed modes.
- Pick equipment pieces manually instead of using automatic optimization.
- Lock saved builds so their selected equipment remains unchanged.
- Work out character speed for planning and side-by-side comparison.

Yes. You can change weighted attributes and target speed modes, choose equipment manually, and lock the equipment assigned to a saved build.

### Are PvP and guild battle records supported?

Yes. The toolkit includes PvP history, GvG team and result tracking, and references for battle-related strategies.

Open the latest build link or review the repository for newer releases. A later version may update data, recommendations, or supported workflows.

### Is offline use available?

Browser local storage and offline support are included. The exact offline experience depends on the browser and the way the files are loaded.

### Will it run in any browser?

The tool is built for web browsers. Browser configuration can affect local storage, offline behavior, and Google Sheets synchronization.

### Does the toolkit connect to Google Sheets?

Yes. Google Sheets synchronization is supported. After opening the tool, follow the provided synchronization workflow.
